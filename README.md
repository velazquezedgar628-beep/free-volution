# Free-Volution

Responsive, single-page preview for the Free-Volution / Global Evolution Network concept.

## Preview

Open `index.html` in a browser. The page includes Spanish, English, French, and Portuguese copy, a responsive navigation menu, a Zambia-focused roadmap, a community initiative demo form, a proposed 40/45/15 fund allocation, and a sample contribution selector.

## Demo limitations

- The initiative form does not transmit or store information.
- The contribution selector does not initiate or process payments.
- The roadmap and 40/45/15 allocation are illustrative proposals, not verified operating commitments or audited financial figures.
- Photos and typefaces load from external Unsplash and Google Fonts URLs when internet access is available.

This repository contains a design preview, not a live fundraising service.
